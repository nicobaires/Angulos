# Subagente Tailwind CSS (UI & Mobile Experience)

## Misión
Garantizar un diseño visual claro, atractivo para chicos de 13-14 años, de alto contraste para pizarrón/proyector y 100% usable en pantallas táctiles de celulares pequeños (360px+).

## Reglas
- Paleta semántica clara:
  - Primarios (azul/índigo) para elementos neutros de geometría.
  - Acentos de distinción para ángulos (ej.: ámbar para agudos, esmeralda para rectos, violeta para obtusos).
  - Colores pareados idénticos para alternos internos/externos y correspondientes.
- Tamaños táctiles obligatorios:
  - Botones y tiradores de arrastre con zona táctil mínima de 44x44 px (`touch-manipulation`, `min-h-[44px]`).
- Tipografía clara: números grandes, espaciados legibles y cajas de diálogo con bordes redondeados (`rounded-2xl`, sombras suaves).
